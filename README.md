# HK People Movement · 香港人口流動數據台

A static dashboard presenting Hong Kong people-movement data — population identity, IMMD crossings, HKIA flight mix, LegCo briefings, destination-country immigration records — and showing where the popular **"airport HK-resident net outflow ≈ international emigration"** framing diverges from the C&SD population accounting identity.

Built as an open response to [atseed.co/hkborder](https://atseed.co/hkborder/). Not adversarial — methodology-transparent. The original author's choice of the airport control point as IMMD's cleanest signal is correct; the quarrel is narrow: that one metric is labelled `international emigration` while it (a) misses major inflow channels and (b) sign-disagrees with the C&SD identity over 2021–2023.

> **TL;DR** — Cumulative 2021–2023, IMMD HK-Resident airport net out reads **−485K** (outflow). Over the same window, the C&SD identity-derived "Other net migration" reads **+13K** (slight inflow). Same population, different question.

---

## Architecture

- **Static site** built with [Observable Framework](https://observablehq.com/framework), deploys to **Cloudflare Pages**.
- **Data pipeline** (`pipeline/`) refreshes IMMD CSV + HKIA flights on demand via `make data` — refresh whenever you want a snapshot, no cron.
- **All numbers traceable** to a primary source — pinned PDF in `data/legco_sources/` or live fetch from C&SD / IMMD / HKIA / CAD.
- **Validation gate**: `pipeline/validate.py` blocks the build if any number in `data/hk_population_master.json` lacks a `source` field.

### Why not Streamlit?

Streamlit needs a long-running Python server. Cloudflare Pages serves static assets; the only Cloudflare route to host Streamlit is Containers, which is overkill for a read-only daily-refresh dashboard. Observable Framework produces a static site that runs entirely in the browser. See `openspec/changes/build-migration-dashboard/design.md` D1 for the full rationale.

## Local dev

```bash
make install            # node + python deps
make data               # refresh data/ from upstream (IMMD + HKIA), rebuild aggregates
make validate           # check every number in master JSON has a source
make dev                # observable preview at http://localhost:3000
make build              # static site to dist/
```

Requires Node ≥ 20 and Python ≥ 3.11.

## Deploy

```bash
make build
wrangler pages deploy dist --project-name=hk-people-movement
```

Or wire Cloudflare Pages' built-in GitHub integration to build on push (no cron needed; refresh data manually with `make data` when you want a new snapshot).
